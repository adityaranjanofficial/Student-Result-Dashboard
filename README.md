• STUDENT RESULT DASHBOARD
A modern and responsive web-based Student Result Dashboard built using HTML, CSS and JavaScript.

1. LIVE DEMO
👉 [View Live Website](https://adityaranjanofficial.github.io/Student-Result-Dashboard/)

2. ABOUT THIS PROJECT:
Student Result Dashboard is a simple web application designed to display student academic performance in a clean and user-friendly interface.
Users can enter a student's roll number and view the corresponding result information.

3. FEATURES:
- 📱 Fully responsive design
- 🔎 Roll number based result search
- 🎓 Student profile section
- 📊 Percentage and grade display
- 📚 Subject-wise marks
- ✅ Pass/Fail status
- 🎨 Modern and clean user interface
- ⚡ Lightweight and fast
- 🌐 Hosted using GitHub Pages

4. TECHNOLOGIES USED:
- HTML5
- CSS3
- JavaScript
- GitHub Pages
